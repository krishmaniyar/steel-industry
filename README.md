## Steel Industry Load Type Prediction

End-to-end machine learning pipeline to predict steel industry load types (Light_Load, Medium_Load, Maximum_Load). The project includes reproducible notebooks for data ingestion, validation, and transformation, plus a Python script to train and evaluate multiple classifiers and persist the best model and metadata.

### Repository Structure
- `01_data_ingestion.ipynb`: Load raw data (`Steel_industry_data.csv`) and perform initial cleaning.
- `02_data_validation.ipynb`: Validate schema, missingness, and quality; export `validated_data.csv`.
- `03_data_transformation.ipynb`: Feature engineering and encoding; export `transformed_data.csv`, `encoders.pkl`, `feature_names.pkl`, `transformation_metadata.pkl`.
- `04_model_trainer.ipynb`: Notebook variant of model training and comparison.
- `model_training_script.py`: CLI-style script to train many ML models, compare, evaluate best on test set, and save artifacts.
- `debug_data.py`: Quick diagnostic script for `transformed_data.csv` readiness.
- Artifacts (created by notebooks/scripts):
  - `ingested_data.csv`, `validated_data.csv`, `transformed_data.csv`
  - `encoders.pkl`, `feature_names.pkl`, `transformation_metadata.pkl`
  - `best_model_<name>.pkl`, `model_metadata.pkl`, `feature_importance.csv` (if produced), `comprehensive_results.pkl`

### Quickstart
1) Open notebooks in order and run all cells:
   - `01_data_ingestion.ipynb`
   - `02_data_validation.ipynb`
   - `03_data_transformation.ipynb`

2) (Optional) Verify transformed data is model-ready:
```bash
python debug_data.py
```

3) Train models and save the best one:
```bash
python model_training_script.py
```

Outputs from step (3) include:
- Best model saved as `best_model_<model_name>.pkl`
- Metadata saved as `model_metadata.pkl` (model params, features, metrics, class mapping, timestamp)
- Console report with validation metrics for all models and final test set metrics for the best model

### How the Training Script Works
`model_training_script.py` expects the following files generated by the transformation notebook:
- `transformed_data.csv` containing numeric/boolean features and a `target` column
- `encoders.pkl` and `transformation_metadata.pkl` (optional but used for class names)

Pipeline inside the script:
- Loads `transformed_data.csv`
- Selects only numeric/boolean feature columns, excluding `target` and `Load_Type`
- Stratified train/val/test split
- Trains a suite of models (Random Forest, Gradient Boosting, Extra Trees, Logistic Regression, Decision Tree, SVM, KNN, Naive Bayes, MLP, AdaBoost; XGBoost/LightGBM if installed)
- Compares models by validation accuracy (also reports precision/recall/F1 and CV accuracy)
- Retrains the best model on training data and evaluates on the test set
- Saves the best model and `model_metadata.pkl`

### Data
- Raw dataset: `Steel_industry_data.csv` (place in repo root). The ingestion notebook reads this file.
- Intermediate CSVs are produced at each step (`ingested_data.csv`, `validated_data.csv`, `transformed_data.csv`).

### Reproducing Results
1) Ensure `Steel_industry_data.csv` exists in the project root.
2) Run notebooks 01 → 03 to generate `transformed_data.csv` and artifacts.
3) Run `python model_training_script.py`.
4) Check outputs: `best_model_*.pkl`, `model_metadata.pkl`, console metrics, and any optional artifacts.

### Using the Saved Model
Example (Python):
```python
import joblib
import pandas as pd

model = joblib.load('best_model_lightgbm.pkl')  # example filename
meta = joblib.load('model_metadata.pkl')

# Prepare a DataFrame with the same feature columns used for training
X = pd.read_csv('transformed_data.csv')[meta['feature_names']]
preds = model.predict(X)
```

Note: You must supply features with the exact columns in `model_metadata.pkl` (`feature_names`). If you are making predictions on new raw data, reproduce the transformation steps from `03_data_transformation.ipynb` (including encoders and any scaling) before calling `model.predict`.

### Troubleshooting
- Missing files error when training: run notebooks `01_data_ingestion.ipynb` → `03_data_transformation.ipynb` first.
- String columns detected in features: re-run `03_data_transformation.ipynb`; ensure categorical columns are encoded. You can also inspect with `python debug_data.py`.
- XGBoost/LightGBM not used: install them (uncomment in `requirements-minimal.txt` or use `requirements.txt`). The script will detect availability automatically.
